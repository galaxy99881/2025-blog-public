# 欢迎来到我的个人网站

你好，我是李志新（Zhixin Li），浙江大学超声医学专业博士研究生，也是一名医师研究者。

我的工作聚焦于临床医学、医学影像与人工智能的交叉领域，包括超声人工智能、医学影像筛查与预测、多模态学习、多中心研究和可解释人工智能。

我希望这里既能记录研究过程与技术思考，也能展示经得起复核的开源工作。相比只追求漂亮的结果，我更关心方法是否真实、可复现，以及结论是否有充分证据支持。

你可以在[关于我](https://galaxy99881.github.io/2025-blog-public/about/)了解我的教育经历与研究方向，也可以在[项目](https://galaxy99881.github.io/2025-blog-public/projects/)查看近期的研究和开源工作。

欢迎通过 [GitHub](https://github.com/galaxy99881) 或邮件 [lizhixin@zju.edu.cn](mailto:lizhixin@zju.edu.cn) 与我交流。
